## ⚡ Proyecto Destacado: Predicción de Demanda Energética (PJM)

Este bloque de archivos recopila el pipeline completo de análisis, ingeniería de datos y modelado predictivo de consumo eléctrico utilizando PySpark, SQL, Machine Learning y Deep Learning:

* **`PJME_comentado.ipynb`** - **Pipeline principal**: Cuaderno que integra el ETL con PySpark (limpieza y ventanas temporales), ingeniería de características y entrenamiento de modelos predictivos (**Random Forest** y **LSTM**).
* **`PJME_hourly.csv`** - **Dataset inicial**: Conjunto de datos histórico original con los registros horarios de consumo eléctrico de PJM.
* **`01_schema.sql` y `02_extraction.sql`** - **Scripts SQL**: Consultas estructuradas para la gestión, estructuración y extracción de datos del modelo relacional.
* **`Informe_Tecnico_Prediccion_Demanda...pdf`** - **Informe Técnico**: Documentación ejecutiva detallada con las conclusiones, métricas de rendimiento (RMSE, MAE) y gráficas comparativas entre los modelos.
